# evoxAstroMuscle
AstroMuscle infiere, sin diagnosticar, el riesgo de atrofia muscular en astronautas de misiones largas. Compara cada semana la fuerza de agarre, la carga en ARED y la masa corporal con la línea base, asigna riesgo bajo, moderado o alto (&lt;10 %, 10–19.9 %, ≥20 %) y alerta por síntomas diarios. Prototipo para NASA Space Apps 2026.
